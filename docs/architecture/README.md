# Architecture Documentation

This directory contains architectural diagrams for the Down Detector Down Detector project using the C4 model.

## C4 Model Diagrams

The C4 model provides hierarchical views of software architecture:

1. **System Context** - Shows the system and its relationships with users and external systems
2. **Container** - Shows the high-level technology choices and how they communicate
3. **Component** - Shows components within containers (future, if needed)
4. **Code** - Shows implementation details (future, if needed)

## Diagrams

- [System Context Diagram](c4-context.md) - Overall system view
- [Container Diagram](c4-container.md) - Technology and deployment view
